This section contains the 3D models used in the project. These models are essential for visualizing and simulating the drone and its components within the application.

The original low-poly scenery in `details-campo.obj`, `details-citta.obj`,
`details-metropoli.obj`, `details-isola.obj`, and `scenery.mtl` is generated by
`python3 tools/build-scenery.py` from the repository root. These assets use solid
materials, require no additional textures, and are covered by the project license.
